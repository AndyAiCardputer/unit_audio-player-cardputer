## 📦 Что добавлено?

### 1. 💿 Jamaican Vinyl Splash Screen

**Крутая заставка при загрузке плеера!**

🎬 **Анимация (~3 секунды):**
- 🔴 Конверт с ямайской рамкой (красный-желтый-зеленый)
- 💿 Виниловая пластинка выезжает из конверта
- 🔄 Пластинка вращается
- 🎵 5 нот вылетают в разные стороны
- 📝 Текст "AndyShuffle v4.29" появляется буква за буквой

✨ **Фишки:**
- Уникальная ямайская цветовая схема 🇯🇲
- Можно пропустить любой кнопкой ⏭️
- Показывается только 1 раз за сессию
- Ретро-стиль виниловой пластинки 📀

---

### 2. 💚 Matrix Rain Visualization

**Легендарный эффект из фильма "Матрица"!**

🎨 **Характеристики:**
- 🟢 Классический зеленый цвет
- 📊 40 столбцов падающих символов
- ♪♫ Музыкальные ноты (каждый ~20-й символ)
- ✨ Trail эффект (затухающий след)
- 🎶 Скорость зависит от музыки

🎮 **Как включить:**
```
Нажми V 3 раза:
V → Bars (столбики)
V → Waves (волны)
V → MATRIX! 💚
V → Выход
```

## 🎯 Быстрый старт

### Загрузка:
1. Откройте `audio_player_unit.ino` в Arduino IDE
2. Выберите плату: **M5Stack Cardputer**
3. Нажмите **Upload** ➡️

### Первый запуск:
1. Увидите Jamaican Vinyl заставку 💿
2. Нажмите любую кнопку чтобы пропустить (или подождите 3 сек)
3. Плеер готов к работе! 🎵

### Попробуйте Matrix:
1. Нажмите **V** (3 раза)
2. Наслаждайтесь зелеными символами! 💚
3. **ESC** для выхода

## 🎮 Управление

### Основное:
| Кнопка | Действие |
|--------|----------|
| **BtnA** (1x) | Play/Pause |
| **BtnA** (2x) | Next |
| **BtnA** (3x) | Previous |
| **+/-** | Volume |
| **V** | Визуализация (3 режима) |
| **I** | Информация |

### В заставке:
| Кнопка | Действие |
|--------|----------|
| **Любая** | Пропустить заставку |

### В Matrix:
| Кнопка | Действие |
|--------|----------|
| **V** | Следующий режим |
| **ESC** | Выход |

## 💡 Советы

### Для максимального wow-эффекта:
1. 🎵 Включите reggae музыку (Bob Marley!)
2. 💿 Дождитесь полной заставки
3. 💚 Переключитесь на Matrix Rain
4. ✨ Покажите друзьям!

### Производительность:
- Matrix обновляется каждые 80ms (~12 FPS)
- Низкая нагрузка на CPU
- Плавная анимация даже на полной скорости

### Кастомизация:
Хотите изменить цвета или скорость?
```cpp

// Jamaican colors:
RED, YELLOW, GREEN // в drawVinylRecord()
```

## 🐛 Известные особенности

1. **Заставка показывается 1 раз**
   - Это фича! Не баг.
   - Перезагрузите плеер чтобы увидеть снова

2. **Matrix может "лагать"**
   - Это эффект! Как в настоящей Матрице
   - Если сильно лагает, увеличьте interval

3. **Музыкальные символы редкие**
   - Каждый ~20-й символ
   - Специально для "охоты за нотами"
